# JNHL Commerce

Vitrine responsiva de produtos e ofertas em múltiplas categorias.

## Publicar no GitHub Pages
1. Envie `index.html` e `cadeira-praia.png` para a raiz do repositório.
2. No GitHub, abra **Settings → Pages**.
3. Em **Build and deployment**, escolha **Deploy from a branch**.
4. Selecione a branch `main` e a pasta `/ (root)`, depois clique em **Save**.
5. Aguarde a publicação.

Mantenha `index.html` e `cadeira-praia.png` na mesma pasta. O primeiro produto usa o link de afiliado fornecido pelo proprietário. Confira preço e disponibilidade no site do vendedor.
